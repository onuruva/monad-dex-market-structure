# Frozen inputs and derived tables

All dates use UTC. Addresses and hashes are lowercase strings. `chain_id=143`.
Amounts, prices, liquidity integers and gas fields are preserved as exact source
strings; integer fields may be parsed only where their range is safe.

## swaps.csv.gz

402,062 observed v4 Swap events. `id` is `log_<block_hash>_<log_index>`, not a transaction hash.

| Field | Meaning |
|---|---|
| id | Unique source event ID |
| block_number, block_timestamp | Chain block number and Unix timestamp |
| transaction_hash, transaction_index, log_index | Transaction identity and chain ordering |
| pool_id | Pool identifier from the indexed Swap topic |
| swap_caller | Event sender; can be a router, not the transaction origin |
| amount0_raw, amount1_raw | Signed integer changes to the caller's token balances; positive means caller receives |
| sqrt_price_x96 | Raw post-swap square-root price scaled by 2^96 |
| active_liquidity | Post-swap active liquidity in the current tick range |
| tick | Signed post-swap tick |
| swap_fee_pips | Fee field reported by the event, in millionths |

`pools.json` maps pool ID to currency0/currency1, fee configuration, tick spacing,
hooks and historical Initialize metadata. `token_metadata.json` maps addresses
to name, symbol and decimals. Native MON uses the zero address. Symbols can be
duplicated; addresses are authoritative identities.

## transaction_origins.csv.gz

301,134 enriched transactions, one per requested hash.

| Field | Meaning |
|---|---|
| chain_id | Monad mainnet identifier 143 |
| transaction_hash, block_hash | Canonical transaction and containing block |
| block_number, transaction_index, block_timestamp | Block identity, order and time |
| tx_from | Originating onchain address; not verified beneficial owner or human |
| tx_to | Direct transaction recipient, not necessarily the final pool |
| transaction_type | EVM transaction type |
| input_selector | First four input bytes including 0x; not a full call trace |
| receipt_status | Receipt success flag; 1 for every matched record |
| receipt_gas_used, receipt_effective_gas_price | Actual transaction receipt fields; not per-swap cost attribution |
| provenance | Enriched-transaction source label |

The `independent_sender_probe.json` contains the earlier 51 historical RPC
transaction probes. It is a technical cross-check, not a representative
behavioral sample. `independent_raw_swap_sample.json` contains 100 seeded raw
logs for independent ABI decoding checks.

## Other source inputs

- `non_swap_events.json.gz`: all 7,084 collected non-Swap manager logs in the week.
- `uniswap_v4_initialize_history.json.gz`: historical pool Initialize logs used to identify active pools.
- `ecosystem_dex_volume_snapshot.json`: frozen DefiLlama daily-volume payload. Protocol `category == Dexs` defines the principal venue-volume universe.
- `metadata_evidence.json`, `historical_decimals_evidence.json`: metadata call evidence and first-use/end-of-sample decimal checks.
- `raw_audit.json`, `snapshot_manifest.json`: source row/key counts and the original exported Swap snapshot identity.
- `data_manifest.json`: exact SHA256 and sizes for all required frozen inputs. Large gzip inputs are split into binary parts below 25 MiB; `materialize_inputs.py` restores their exact bytes.

## Derived results

| File | Interpretation |
|---|---|
| pool_activity.csv | One row per active v4 pool; event, transaction and caller counts |
| pool_valued_volume.csv | Eligible USD-equivalent pool-execution notional; missing valuations excluded |
| daily_activity.csv | Swap activity by UTC day |
| ecosystem_venue_shares.csv | Same-week provider DEX-category venue volume and shares |
| ecosystem_family_shares.csv | Provider parent-family grouping, not verified legal ownership |
| origin_account_activity.csv | Originating-address executions, transactions, active days, pools and valued notional |
| origin_daily_activity.csv | Daily originating accounts and first/prior observations inside the sample |
| origin_within_week_cohorts.csv | First-observed cohorts and censored within-week recurrence; last-day rate undefined |
| valuation_sensitivity.csv | Hypothetical peg and reference-age/leg-discrepancy sensitivity |
| forecast_summary.csv | Chronological holdout MSE/RMSE comparisons and bootstrap intervals |
| order_flow_tests.json | Full nested-model, per-pool, daily and robustness outputs |
| minute_features.csv.gz | Selected-pool minute bins and future last-traded-price targets |
| holdout_predictions.csv.gz | Actual and predicted holdout returns; units are basis points |
| final_input_validation.json | Offline sample and full canonical-origin validation |

The large normalized-event and valuation-event tables are regenerated by
`run_research.py` and omitted from the distribution. Flags are task-specific;
none alone identifies manipulation. Missing valuations are not zeros.

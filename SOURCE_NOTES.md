# Source and attribution notes

The dataset is a frozen public-blockchain sample collected through Goldsky and Neon. Metadata and deployment identities use the official Monad token list and protocol registry. The frozen official token list is provided as identification evidence, not an endorsement of any asset. ABI meanings follow the linked Uniswap v4 event and pool implementations. The venue-volume payload is from DefiLlama and remains provider-reported context. Links and dates are documented in METHODOLOGY.md.

This application package contains no database password, API key, private RPC credential or signed transfer URL. Scripts reading optional online sources require credentials supplied by the reviewer in their own environment. No secrets are needed for offline reproduction.

Original third-party software repositories retain their own licenses; full Solidity source copies are not redistributed in this package. No claim of original authorship of third-party protocol code or provider data is made.
